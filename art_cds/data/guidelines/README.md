# BHIVA guideline text

Plain-text extracts of the BHIVA guidelines live here. They are used only to verify that
statements in the knowledge base match their source. **They are not stored in this repository**:
the text is the copyright of the [British HIV Association](https://bhiva.org).

```bash
python -m tools.fetch_guidelines
```

Documents: adult ART 2022 (2025 interim update), pregnancy and postpartum (2025), and
tuberculosis 2018 (2023 interim update).
